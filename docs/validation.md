# Layout refactor validation

The refactor was verified after integrating reviewed PRs #6 and #7. It moves
configuration, dependency files, download indexes and documentation; no model is
retrained and historical metrics/weights are not regenerated by the layout work.

| Check | Result |
| --- | --- |
| Fresh Python 3.11 virtual environment, `pip install -r requirements.txt` | Installed successfully |
| `python -m pytest -q` in that environment | 59 passed |
| `python -m pip check` | No broken requirements |
| Dataset validator on existing released Parquet | All 90 trips passed |
| LR, DT and GB released pipelines on all 130,919 student-test candidates | Match their saved probability exports within 1e-12 |
| Top-1 choices from reloaded pipelines | Unchanged for every model |
| Shared GB runner on a synthetic five-fold dataset | Trains, evaluates, reloads and exports successfully |
| Canonical fold CSV | Identical bytes to the original LR/DT fold file |
| Documentation relative links | Resolve, including the uploaded comparison report |
| UI Folium map creation/rendering with GPS and route geometry | Passed |

The maximum LR probability difference is 5.55e-16 (floating-point rounding); DT
and GB predictions are bitwise identical. Trained joblib import paths, including
`src.training.preprocessing.to_float64`, remain intact.

The clean-environment test run emits one upstream Starlette/AnyIO deprecation
warning. It does not fail tests or affect API responses. The standalone Streamlit
map smoke check runs without a Streamlit server; a two-laptop interactive demo
was not repeated as part of this filesystem refactor.

Reproduce the ordinary checks from the repository root:

```powershell
py -3.11 -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
.venv/Scripts/python -m pytest -q
.venv/Scripts/python -m pip check
.venv/Scripts/python -m src.data.download_dataset
.venv/Scripts/python -m src.data.validate_dataset
```

Saved baseline metrics remain in `results/models/`. Refactor validation evidence
is summarized in [project_layout.json](../results/validation/project_layout.json).
